<p>Vladimír Gorej is a Prague-based <strong>Senior Full-Stack Engineer</strong> with 17+ years of experience, the last seven specialized in developer tooling for the API specification ecosystem: <strong>OpenAPI</strong>, <strong>AsyncAPI</strong>, <strong>Arazzo</strong>, and <strong>JSON Schema</strong>. Over the years, he has worked as Technical Team Lead at Oracle, Principal Software Engineer at Apiary, and Senior Open Source Engineer at SmartBear, along with other senior engineering and leadership roles at Ubiquiti Networks, SecurityScorecard, and Jentic. Today he is building <a href="https://speclynx.com/">SpecLynx</a>, the open, local-first toolchain for API specifications that he co-founded. Active in the Open Source community for more than fifteen years, he is a <a href="https://github.com/asyncapi/spec">maintainer of the AsyncAPI specification</a>, spent five years as a maintainer of <a href="https://swagger.io">Swagger tools</a>, and is an alumni member of the <a href="https://stars.github.com/alumni/#:~:text=char0n">GitHub Stars program</a>. He holds all Open Source Best Practices certifications awarded by The Linux Foundation, and believes an API spec is only worth as much as the tooling around it: his work is about making APIs usable by developers and AI agents alike.<br>
<br><div><h2>SpecLynx</h2><p><a href="https://speclynx.com/" target="_blank" rel="noreferrer nofollow"><img align="left" width="100" height="100" src="https://vladimirgorej.com/assets/img/speclynx-logo.webp"></a></p><p>Vladimír is a <strong>co-founder</strong> of <a href="https://speclynx.com/">SpecLynx - One toolchain for every API spec</a>. One semantic structure. Every API spec. SpecLynx parses, validates, transforms, and lints OpenAPI, AsyncAPI, Arazzo, Overlay, and JSON Schema through one shared semantic structure. It ships a browser-based Editor, OpenAPI Toolkit for VS Code, CLI, Language Service, and ApiDOM. Local-first, always: runs offline, no accounts, no telemetry, open source under Apache 2.0.</p><br><br></div><br>
<br><div><h2>UseArazzo</h2><p><a href="https://usearazzo.com/" target="_blank" rel="noreferrer nofollow"><img align="left" width="100" height="100" src="https://vladimirgorej.com/assets/img/usearazzo-logo.webp"></a></p><p>Vladimír is a <strong>co-founder</strong> of <a href="https://usearazzo.com/">UseArazzo - The foundational operating system for Arazzo API workflows</a>. UseArazzo is a JavaScript/TypeScript toolkit for Arazzo, the OpenAPI Initiative specification for multi-step API workflows. It parses, resolves, and validates Arazzo Documents against the specification, and runs workflows against live APIs with a step-by-step trace in run order. Open source under Apache-2.0 on <a href="https://github.com/usearazzo">GitHub</a>.</p><br><br></div><br>
<br><div><h2>SwaggerExpert</h2><p><a href="https://swaggerexpert.com/" target="_blank" rel="noreferrer nofollow"><img align="left" width="100" height="100" src="https://vladimirgorej.com/assets/img/swagger-expert-logo.webp"></a></p><p>Vladimír is a <strong>founder</strong> of <a href="https://swaggerexpert.com/">SwaggerExpert</a>. SwaggerExpert is a community dedicated to extensions and libraries enhancing the Swagger/OpenAPI ecosystem. Its core libraries are the <a href="https://github.com/swaggerexpert/arazzo-runtime-expression">Arazzo Runtime Expressions</a> and <a href="https://github.com/swaggerexpert/arazzo-criterion">Arazzo Criterion Object</a> parsers, validators and evaluators, the <a href="https://github.com/swaggerexpert/jsonpath">RFC 9535 JSONPath</a> parser, validator and evaluator, and the <a href="https://github.com/swaggerexpert/json-pointer">RFC 6901 JSON Pointer</a> implementation. It also maintains OpenAPI path and server URL templating parsers, the swagger-editor-validate GitHub Action, an RFC 6265 compliant cookie parser, and more.</p><br><br></div></p>
